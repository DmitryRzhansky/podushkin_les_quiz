# Материалы сайта

## Фотографии и схемы

Все восемь изображений скачаны со страницы действующего квиза:

- Источник: [Mrqz — квиз об аренде земельных массивов в Хабаровске](https://mrqz.me/6ad714203f3950000ff34f4e).
- CDN-адрес материалов: https://cdn.media.marquiz.ru/v1/image/upload/
- Исходные файлы сохранены в оптимизированном WebP. На сайте нет случайных фотостоковых кадров или рендеров базы отдыха.

| Локальный файл | Материал | Использование |
|---|---|---|
| assets/images/field-95-main.webp | Аэросъёмка открытой территории среди леса | Главное фото для массива 9,5 га: полноэкранный экран и итоговая карточка |
| assets/images/field-95-secondary.webp | Дополнительная аэросъёмка массива 9,5 га | Дополнительный кадр сохранён локально; в компактном итоговом экране не выводится |
| assets/images/field-74-access.webp | Аэросъёмка участка с дорогой, соседними массивами и застройкой | Выбор массива 7,4 га и итоговая карточка |
| assets/images/visit-plots.webp | Вид с воздуха на поле, лес и дорогу | Фото для отдельной карточки перед осмотром |

Кадастровые номера на схеме и в тексте результата переписаны из действующего квиза. Их состав и актуальность не проверялись по свежим выпискам ЕГРН; перед публикацией их нужно подтвердить. На странице номера помечены как указанные в предложении; они не представлены как независимо подтверждённые. Разрешённое использование и категория земли также требуют отдельной проверки для каждого массива.

Действующий квиз упоминает видеооблёт, но не содержит прямой ссылки на видео или его файла. Поэтому видео локально не приложено и автоматическая отправка не обещается. Поле resources.videoUrl в конфигурации оставлено пустым.

Рендеры базы отдыха из репозитория не использованы: они не подтверждены как изображения предлагаемых массивов.

## Шрифты и иконки

- assets/fonts/manrope-variable.woff2 — Manrope Variable, скопирован из static/fonts/manrope/ManropeVariable.woff2 проекта «Подушкин лес». В исходной папке отдельный файл лицензии не найден; подтвердите право на распространение шрифта при публикации шаблона.
- assets/icons/fontawesome.min.css, assets/fonts/fa-solid-900.woff2, assets/fonts/fa-brands-400.woff2 — локальные файлы Font Awesome 6.5.2. Источник: [cdnjs](https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.2/). Страница не загружает Font Awesome с CDN при открытии; лицензии Free Font Awesome — CC BY 4.0 для иконок и SIL OFL 1.1 для шрифтов.
